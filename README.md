## Running locally

Clone the repo and open `index.html` directly in your browser:

```
git clone https://github.com/bhuvaneesand0203-ops/<repo-name>.git
cd <repo-name>
open index.html   # or just double-click the file
```

## Deploying with GitHub Pages

1. Push this repo to GitHub (or upload `index.html` directly via the web UI)
2. Go to **Settings → Pages**
3. Under **Source**, select the `main` branch and `/ (root)` folder
4. Save — the site will be live at `https://bhuvaneesand0203-ops.github.io/<repo-name>/`
